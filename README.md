# Git workflow assignment

This repository was created locally before the public GitHub repository.

## Files

- `index.html`: home page.
- `about.html`: about page with the change committed on `feature`.
- `.gitignore`: excludes `*.log` and `temp/`.
- `git_commands.txt`: executed commands with brief explanations.

## Recorded workflow

1. Initial commit with both HTML files.
2. Update to the home page.
3. A commit on the `feature` branch.
4. An explicit merge of `feature` into `main`.
5. Commit the ignore rules.
6. Add a temporary announcement.
7. Revert that announcement while retaining its commit in history.
8. Commit this documentation.

Both `main` and `feature` are published. The temporary announcement is absent from the final home page. Open `index.html` locally to view the site. No installation or build step is needed.
